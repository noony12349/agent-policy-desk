交易风险提示

这是链上规则和代币托管工具，不是收益产品。它不会替你自动交易，也不保证本金或任何回报。

执行者取出的代币会进入执行者自己的地址。归还之前，合约拿不回这笔钱。关闭策略只能退回仍留在合约里的余额。少还的差额立刻记为亏损，达到上限后不能再取。

成交量由执行者在归还时自行填报，合约不核验外部订单是否真实成交。请只存入你能承受损失的金额，并核对执行者地址。

合约开源、不可升级，也没有管理员。没有人能用隐藏入口划走托管。本页只使用浏览器注入的钱包，不提供扫码或配对码，不收集助记词、私钥、PIN 或 API 密钥。每笔授权和转账都会在钱包里再次确认。
